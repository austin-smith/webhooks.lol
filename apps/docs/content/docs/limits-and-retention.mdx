webhooks.lol is a tool for testing and debugging, not durable storage. A few
limits keep it fast and fair to share.

## Retention

Each endpoint keeps its **latest 500 requests**. New requests keep arriving past
that point, but the oldest are dropped to stay within the cap. You can also
delete an endpoint's captured requests yourself with the **Clear** button in the
inspector.

If you need to keep a request, copy its body or raw form from the detail pane
before it rotates out.

## Payload size

Request bodies are capped at **1 MiB**. A larger body is rejected with a `413`
and is not stored:

```json
{ "ok": false, "error": "Request body too large.", "maxBodyBytes": 1048576 }
```

## Rate limits

Rate limits keep one caller or endpoint from overwhelming the service. When a
rate limit is exceeded, the request is rejected with a `429` and a
`Retry-After` header.

Limits are checked by scope. For example, a captured request must fit under the
per-endpoint, per-client, and global capture limits. The first exhausted scope
wins.

| Feature                      | Scope              | Limit                      |
| ---------------------------- | ------------------ | -------------------------- |
| Endpoint creation            | Per client         | 100 endpoints per hour     |
| Endpoint creation            | Global             | 360,000 endpoints per hour |
| Capturing requests           | Per endpoint       | 600 requests per minute    |
| Capturing requests           | Per client         | 1,200 requests per minute  |
| Capturing requests           | Global             | 60,000 requests per minute |
| Captured request body volume | Per endpoint       | 1 GiB per day              |
| Replaying requests           | Per endpoint       | 120 replays per minute     |
| Replaying requests           | Per client         | 60 replays per minute      |
| Replaying requests           | Per stored request | 60 replays per minute      |
| Replaying requests           | Global             | 600 replays per minute     |

A **client** is one caller of the service, such as the browser, script, or
service sending the request.

A **stored request** is the original captured request you replay from. If request
`abc123` is replayed several times, each replay counts against the replay limits
above, including the `abc123` stored-request limit.

## Configuration caps

These caps apply to stored data and endpoint configuration.

| Area                       | Limit                                                  |
| -------------------------- | ------------------------------------------------------ |
| Stored requests            | Latest 500 requests per endpoint                       |
| Captured request body size | 1 MiB per request                                      |
| Custom response body size  | 64 KiB                                                 |
| Forwarding targets         | 5 enabled targets per endpoint                         |
| Forwarding target rows     | 20 total rows per endpoint, including disabled targets |
