webhooks.lol gives you a unique receive URL that captures every HTTP request
sent to it. Point a webhook, script, or service at the URL and watch each
request appear live, then inspect its method, headers, query string, and body.

It is built for testing and debugging webhooks and any other HTTP request you
want to see exactly as it was sent.

## How it works

- **Endpoint**: A unique URL that captures HTTP requests. Opening the app
  creates one automatically. Endpoint URLs are shaped like
  `https://webhooks.lol/api/hook/<endpoint-id>`.
- **Request list**: Requests received by the endpoint, newest first.
- **Request detail**: The selected request's method, path, query string,
  headers, and body.

No account is required. Opening the app creates a working anonymous endpoint
immediately. Create an account to keep endpoints available across signed-in
browser sessions.

## Quickstart

1. **Open the app.** A fresh endpoint is created automatically.
2. **Copy the receive URL** from the bar at the top of the inspector.
3. **Send a request** to it from your service, or from a terminal:

```bash
curl -X POST https://webhooks.lol/api/hook/<endpoint-id> \
  -H "content-type: application/json" \
  -d '{"hello":"world"}'
```

4. **Watch it land.** The request appears in the list instantly. Select it to
   see the parsed body, headers, query string, and the raw HTTP request.

That is the whole loop. The rest of these docs cover working with endpoints and
accounts, reading, searching, and replaying captured requests, forwarding new
traffic, custom responses, and the limits that apply.
